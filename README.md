## 按小时计费还是月付：先算一笔账

官方小时价是 **$0.012/小时**起。一个月按 730 小时算，$0.012 × 730 = **$8.76**，比月付 $7.71 贵大约 $1。也就是说，24 小时不停机跑满整月，月付更便宜。

小时计费的价值在短时任务。编译一次项目、压测半小时、验证某个应用镜像能不能正常跑起来、临时给客户演示一套环境，用完直接释放，只按实际开机时长扣费。这种做法月付做不到，因为月付下不管用不用，这一个月都照收钱。

判断标准很简单：预计连续运行超过 20 天，选月付；不到 20 天的一次性任务，选小时计费。两种方式都不需要签合同，官方写的是随时可以取消。
